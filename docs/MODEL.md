# 模型与复现口径

## 1. 来源与范围

依据王正本科毕业论文《基于 LQR 控制的一阶倒立摆 Simulink 仿真》（2026 年 4 月），第 2–4 章、表 1–3，重新实现线性倒立摆模型、LQR 状态反馈、三组权重对比和矩形脉冲扰动实验。论文描述的平台为 MATLAB R2024b / Simulink，本次也在该版本实际运行。

| 参数 | 含义 | 值 |
|---|---|---:|
| M | 小车质量 | 0.50 kg |
| m | 摆杆质量 | 0.20 kg |
| b | 小车黏性阻尼 | 0.10 N·s/m |
| l | 转轴至摆杆质心距离 | 0.30 m |
| I | 绕质心转动惯量 | 0.006 kg·m² |
| g | 重力加速度 | 9.81 m/s² |

`l` 是半杆长意义的质心距离，不是整根杆长。状态为 `z=[x, v, theta, omega]^T`，角度内部统一用弧度，图表转成度。输入是水平力 N，不是力矩。

## 2. 必须说明的符号修正

论文式 (6) 写为 `xc=x+l*sin(theta)`，式 (22)–(27) 的耦合符号与此一致；但式 (29)–(34) 的数值 A、B 矩阵对应相反的摆角方向。这会导致直接从前面的几何公式推导时出现符号冲突。

本项目保留论文用于仿真的 **数值 A、B 和 K**，统一几何约定为：

```
xc = x - l sin(theta)
yc = l cos(theta)
theta = 0：竖直向上；正 theta：质心相对支点向左。
```

相应动力学为：

```
(M+m) x_ddot + b x_dot - m l cos(theta) theta_ddot
    + m l sin(theta) theta_dot^2 = u
(I+m l^2) theta_ddot - m l cos(theta) x_ddot - m g l sin(theta) = 0
```

若坚持使用论文式 (6) 的角度方向，需要同步变换 `theta、omega` 的符号以及矩阵和增益。两种约定都可以，不能混用。`cartpole_nonlinear.m` 使用上述一致的几何约定；测试通过中心有限差分验证其在零平衡点的 Jacobian 等于线性 A、B。

## 3. 线性系统与 LQR

设 `d=I(M+m)+M m l²`，则：

```
A = [0  1                  0                     0
     0 -(I+m*l²)*b/d       m²*g*l²/d              0
     0  0                  0                     1
     0 -m*l*b/d            m*g*l*(M+m)/d          0]
B = [0; (I+m*l²)/d; 0; m*l/d]
```

由原始物理参数计算全精度矩阵，不直接输入论文四位小数的显示值。控制律 `u=-Kz`，目标 `J=integral(z'Qz + u'Ru) dt`，调用 MATLAB `lqr` 求解连续时间代数 Riccati 方程。

| 方案 | diag(Q) | R |
|---|---|---:|
| A（基准） | 120, 8, 600, 12 | 0.08 |
| B（增大控制代价） | 120, 8, 600, 12 | 0.20 |
| C（增大状态代价） | 150, 10, 800, 16 | 0.08 |

基准增益约为 `[-38.7298, -36.3830, 160.9258, 29.6787]`。测试检查可控性、CARE 残差和所有闭环极点实部为负。它们证明本线性模型的闭环性质，不证明任意大角度或真实硬件稳定。

## 4. 工况与指标

- 初始偏角：`z0=[0,0,5*pi/180,0]`；仿真 8 s。A/B/C 使用相同对象和初态。
- 开环：相同初态，`u=0`，仿真 2 s。大角度时线性模型数值已超出物理适用范围，不能解释为实物轨迹。
- 扰动：零初态，A 组控制器，1.0–1.2 s 施加 2 N 矩形脉冲；仿真 8 s。`plant_input=u+d`，图表的控制力峰值仅指反馈力 `u`。
- 主要计算：`ode45`，相对容差 `1e-10`、绝对容差 `1e-12`、最大积分步长 0.01 s；输出采样 0.001 s。
- 脉冲分三段积分，强制经过 1.0 s 和 1.2 s 两个不连续点，避免自适应求解器跨过短脉冲。
- Simulink 独立使用 State-Space 对象和反馈环路，最大步长 0.001 s；模型工作区保存参数，可直接打开 `.slx` 仿真。
- 摆角 2% 误差带指初始 5° 的 2%，即 **±0.1°**，不是最终零值的 2%。调节时间采用最后一次越界后的第一个采样时刻。
- 位移报告采用明确的 **±0.002 m** 阈值。论文初始工况的“小范围”未明确数值，因此不得据此声称复现了论文全部位移收敛时间。
- 扰动恢复时间从脉冲结束 1.2 s 起计。所有“保持在误差带”均基于有限的 8 s 观察窗。

`nonlinear_A_extension.csv` 是本次追加的一致性探索，不属于原论文的线性仿真证据。未加入执行器饱和、测量噪声、离散控制器或状态观测器，也未开展实物验证。
